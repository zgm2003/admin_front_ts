# 上传规则扩展名全选

## 目标

降低上传规则编辑成本，让管理员可以一次选择某一类的全部扩展名，同时保留图片扩展名和文件扩展名的独立授权边界。

## 交互设计

- `Image Exts` 和 `File Exts` 两个 `el-select-v2` 分别提供一个面板顶部的“全选”复选框。
- 当前组没有选中项时，复选框未选中；只选中部分时显示半选；全部选中时显示选中。
- 点击未全选或半选状态的复选框，选择该组全部扩展名。
- 点击已全选状态的复选框，清空该组扩展名。
- 全选控件只负责更新真实扩展名数组，不向 API payload 写入伪造的扩展名值。

## 实现边界

- 复用后端 `pageInit` 返回的扩展名选项作为唯一选项源。
- 在页面 composable 中集中计算全选/半选状态和切换逻辑，模板只负责绑定。
- 不改变 API、数据库结构、扩展名契约或保存校验规则。
